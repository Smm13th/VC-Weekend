# ВЭД-помощник

Прототип проверки валютного договора и заявки на перевод. Все документы и реквизиты в репозитории синтетические. Пороговые значения и правовые трактовки требуют сверки с банком и юристами до пилота.

## Backend

Требуется Go 1.27.3 или совместимый toolchain. Команды запускаются из `backend/`:

```sh
go test ./...
go run ./cmd/eval
```

`cmd/eval` прогоняет 20 наборов из `backend/eval/`, сравнивает идентификаторы найденных правил с ожидаемыми и печатает precision/recall. Код выхода `1` означает, что есть расхождения; `2` — ошибка чтения или разбора набора. На текущем наборе получено 20/20 совпадений.

Запустить HTTP API из корня репозитория: `./scripts/run.sh`. Сервер слушает порт 8080. Есть `GET /health`, `GET /api/demo`, `GET /api/reference`, `POST /api/check` (JSON `CaseInput`), `POST /api/analyze` (multipart `documents[]`, поля `form` и `task` по необходимости) и `POST /api/ai/explain`.

### DeepSeek (fish на macOS)

Ключ задаётся только в терминале backend и не встраивается во Flutter или браузер. Из корня проекта выполните:

```fish
set -x DEEPSEEK_API_KEY 'ваш-api-ключ'
./scripts/run.sh
```

Откройте второй терминал для Flutter. Команда запуска сервера унаследует переменную из fish. При новом окне терминала ключ нужно задать снова. Чтобы отключить DeepSeek, нажмите `Ctrl+C` в терминале сервера или запустите сервер без `DEEPSEEK_API_KEY`; тогда «Почему?» будет использовать локальное пояснение. После смены ключа перезапустите backend. Если порт 8080 занят предыдущим сервером, остановите его в исходном терминале сочетанием `Ctrl+C`.

Необязательные переменные: `DEEPSEEK_MODEL` (по умолчанию `deepseek-v4-flash`), `DEEPSEEK_ENDPOINT` (по умолчанию `https://api.deepseek.com/chat/completions`). Для OpenAI-совместимой локальной модели укажите локальный endpoint и модель; ключ можно не задавать.

При нажатии «Почему?» приложение отправляет backend только ID правила. Backend формирует запрос из собственного общего пояснения справочника. Текст документов, цитаты, имена, БИН и номера счетов в этот вызов DeepSeek не входят. При сетевой ошибке интерфейс получает локальный запасной ответ. Интеграция и маскирование реализованы в `backend/internal/ai`, маршрут — `backend/internal/api`.

## Статус реализации

Парсер DOCX/PDF, извлечение полей, детерминированные проверки и HTTP API находятся в Go backend. Flutter UI реализован в `mobile/lib/` и подключается к API. Для создания платформенных Flutter runner и запуска шаги приведены в [`mobile/README.md`](mobile/README.md). Постоянное хранилище SQLite, APK и сквозные браузерные снимки пока не реализованы в этом архиве.

## Демонстрация

1. Покажите чистый и дефектный договор из одного из пяти наборов `backend/samples/`.
2. Запустите тесты и оценочный набор командами выше.
3. Объясните, что правила и справочники дают воспроизводимый результат, а ИИ предназначен для пояснений; проверка и подписание должны оставаться действием человека.

Не помещайте настоящие персональные или банковские данные в демонстрационные материалы. Не вставляйте API-ключ в исходный код: передавайте его через секреты окружения при подключении приложения.
